# Anime Data Analysis Project 

## Overview
This project focuses on analyzing an anime dataset using Python 
for data cleaning, preprocessing, and exploratory data analysis.

## What I Did
- Loaded and explored the dataset using Pandas
- Identified missing values and data quality issues
- Handled null values in the rating column using the mean
- Filled missing values in the type column using the mode
- Cleaned and prepared the dataset for analysis
- Explored relationships between anime ratings, genres, and popularity
- Created visualizations to better understand the data

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Key Insights
- Some anime categories achieved higher average ratings than others
- Missing values can significantly affect analysis results if not handled correctly
- Data cleaning is an essential step in every data analysis project

## Project Goal
Practice the complete workflow of a Data Analyst: understanding 
raw data, cleaning it, analyzing it, and transforming it into useful insights.
